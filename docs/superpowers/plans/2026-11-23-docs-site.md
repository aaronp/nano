# Nano docs site: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a VitePress docs site at `/docs` (Concepts 1–10 on the template, then four Recipes), every sample a region of a real tested file, every runnable one with "Open in nano".
**Architecture:** `docs-site/` (own package and lockfile, outside the Bun workspaces) builds with VitePress into `packages/ui-workspace/public/docs/`, after the host build; `scripts/check-regions.ts` fails the build on a missing embed or an Open in nano target that is not built; the Pages workflow builds it with `DOCS_BASE`.
**Tech Stack:** VitePress `1.6.3` (exact), Vue SFC for one component, Bun, Playwright for the link check.
**Spec:** docs/superpowers/specs/2026-11-23-docs-site-design.md

## Global Constraints
- VitePress pinned exactly: `"vitepress": "1.6.3"`; it is a dependency of `docs-site/package.json` only; root `workspaces` unchanged.
- Output: `packages/ui-workspace/public/docs/` (gitignored: add `packages/ui-workspace/public/docs` to the root `.gitignore`).
- `base`: `process.env.DOCS_BASE ?? '/docs/'`; on Pages `<base_path>/docs/` (`base_path` from `actions/configure-pages`).
- Embeds: `<<< @/../<repo path>#<region>` with `// #region <name>` / `// #endregion` markers; JSON files embedded whole (no region).
- Region markers are the only change to template/example code (CLAUDE.md: no new exports, methods or options; a gap is a board card, not a fix).
- `examples/` files obey the structure test (≤150 lines): a file that would pass 150 with markers gets none (embed the whole file or skip).
- Pages are short (a screen or two, as Elysia's); they link to design.md/the spec instead of restating them.
- Each gap found while writing: a card in `docs/board/board.md` under `## To-Do`, `- parent: t-09`, in the board's card format (see t-10, t-11), listed in the task's report.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.

## Review Focus
1. On a Pages subpath (`DOCS_BASE=/nano/docs/`), Open in nano points at `/nano/?src=examples/<x>/nano.json`, not the domain root.
2. A renamed or removed region, or an Open in nano target not built, fails `bun run build` in `docs-site/` with the file and region named.
3. The exported template still passes `bun scripts/template-check.ts` with its markers.
4. Dark mode: the accent keeps text and links readable (VitePress's default dark theme with nano's accent).
5. `make ui` / `make dev` do not need `docs-site/` installed; the docs are optional locally.
