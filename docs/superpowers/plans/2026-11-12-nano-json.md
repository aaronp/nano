# nano.json Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole working app as a `nano.json`: a File menu (New, Open, Import, Save, Save As, Download), `?src=`, a continuously saved working copy, component config via `config`/`configure`, and saved workspaces as ordered top-level nav items.

**Architecture:** `packages/shell` gains the document schema + validator (`app.ts`) and `<nano-file-menu>`. The host (packages/ui-workspace) gains `src/app/`: `snapshot.ts` (live state → `NanoApp`), `apply.ts` (`NanoApp` → live state, replace or merge, returning notes), `store.ts` (working copy, named apps, title, dirty), `file.ts` (the `file:*` handlers and dialogs), and boot wiring. Components opt into `config`/`configure`. Open/New write the working copy and reload; start-up applies it.

**Tech Stack:** TypeScript, Bun, TypeBox, lit, runes, happy-dom, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-12-nano-json-design.md`

## Global Constraints

- Branch `sandbox`; one commit per task; messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. If a permission check refuses a commit, stop and report.
- Every op typed and described; inputs bounded; elements accessible (real buttons, labels, keyboard, Escape), `--nano-*` tokens, no `<form>`.
- Storage keys: `nano.working`, `nano.apps`, `nano.app`, `nano.title`. Document version `nano: 1`; max 1 MB (UTF-8 of its JSON).
- Reserved instance ids (never written, skipped on load with a note): `platform`, `registry`, `profile`, and `ex-*`. The Main workspace (path `/workspace`) is never written.
- Theme field: `{ id: string; mode?: 'system' | 'light' | 'dark' }` (matches the host's `ThemeChoice`).
- Working-copy autosave debounce: 500 ms.
- Checks: `make test`, root `node_modules/.bin/tsc -p .`, `cd packages/ui-workspace && bun run build`; templates' `bun test`; e2e via `make test-ui` (the user runs it).

## Review Focus

1. A document asking for a *trusted* import is imported sandboxed unless the person ticks it; Cancel changes nothing (Task 5 test).
2. Open/New with unsaved changes asks first; declining leaves the working copy untouched (Task 5 test).
3. `?src=` never overwrites a named app, keeps unsaved work as "Before opening …", and is removed from the address bar (Task 5 test).
4. An instance added in Systems is back after a reload (working copy applied on start-up) (Task 4 test).
5. Hostile documents: > 1 MB, `javascript:` profile href, reserved ids, unknown kinds, deep nesting, wrong version — refused or skipped with notes, never thrown (Tasks 1 and 3 tests).
