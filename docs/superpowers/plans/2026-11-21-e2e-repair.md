# e2e repair: the seven failing browser tests

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `bunx playwright test` passes (27/27), by fixing the two product bugs and updating the stale tests.
**Spec:** the investigation (user: "yes, fix them"). Root causes, verified in a clean worktree at d1a604c:
- **Ring starts lazy pods while hidden.** `<nano-ring>` (packages/ui/src/observe/ring-view.ts, since 9ae61f8)
  mounts every pod's view even while `#/ring` is hidden. A view's first call builds its lazy pod. The template's
  `nano-store` calls `Store/entries`, so a Trusted foreign import asks "Run acme.template … in this page?" right after
  Import (cross-origin:40), and `nano-timer` matches twice (slice:42). The user's rule: nothing starts a pod as a side
  effect (ADR-0031, explicit `getOrCreate`).
- **Import every example, Sandboxed, fails silently.** The raft example's `Cluster/create` input has
  `name: Type.String({ pattern })` (examples/raft/interfaces.ts:44). A frame's schema may not use `pattern`/`format`
  (sandbox/protocol.ts `hasRegex`, ADR-0034: a backtracking pattern would freeze the host). The failure toast renders
  beneath the open modal dialog, so nothing visible happens (examples:200).
- **The Circuit page is gone.** 5a4bb4e removed `#/wiring` and `c-circuit`. slice:4 (`c-circuit .fp[data-instance]`)
  and workflow:95 (`c-circuit path[data-cable]`) still look for it.
- **A race in the test.** `locator('input[data-select-runtime]').all()` doesn't wait, so the uncheck loops run before
  Fetch fills the list (examples:132, 170, 188, 229). examples:181 passes once it waits.
- **The chat workspace is wider than the viewport.** With the chat example the dock is 1450px in a 1280px window
  (nav 248 + dock); after Connections flips back the document stays scrolled 418px sideways and the click on the
  explorer row lands on app-shell's `.frame` (examples:371).
